Changelog

Platform updates

Security fixes, new features, and infrastructure changes — documented as they ship.

June 7, 2026MCP

get_status tool and structured audit logging

Added harmless get_status MCP tool alongside ping. API and MCP workers now emit structured JSON logs for every request — IP, endpoint, success/failure, timestamp, and duration.

June 7, 2026Product

Waitlist API and dashboard sign-in

Homepage waitlist now posts to the API (rate limited, honeypot protected). App dashboard accepts your API token and shows live service health checks.

June 7, 2026Security

Platform security hardening

Added constant-time token verification, rate limiting on auth endpoints, strict CORS allowlists, security headers on all Workers, CSP/HSTS on the public site, and API auth for /v1/* routes. MCP body size limits and Content-Type validation enforced.

June 7, 2026Release

Three-deploy architecture live

Split derhead.app into separate Cloudflare deploys: Pages for the public site, Workers for api.derhead.app and mcp.derhead.app. Domain boundaries enforced — no MCP tools on the marketing site.

June 7, 2026MCP

Test tools shipped on mcp.derhead.app

Initial MCP server deployed with authenticated access and three harmless test tools: ping, echo, and get_time. Tool allowlist enforced in code — no dynamic tool registration.

June 6, 2026Launch

derhead.app goes live

Initial platform launch on Cloudflare. Public site, API worker scaffold, and MCP worker foundation deployed. Early access waitlist open.
