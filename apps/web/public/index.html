Security

Security isn't a feature. It's the foundation.

MCP servers can reach sensitive systems. derhead is designed so you can ship tools confidently — starting with harmless test tools only.

🔐

Auth before every tool call

MCP endpoints require a Bearer token. No token, no tools — period.

📋

Tool allowlists

Only explicitly registered tools are available. Unknown tools are blocked at the server level.

📝

Structured logging

Auth failures, tool calls, and errors are logged as structured JSON for audit and debugging.

🚧

Test tools first

Start with ping and get_status. Don't connect private accounts or data until auth and logging are verified.

FAQ

Common questions.

derhead.app is secure hosting for MCP servers and apps you build in Cursor — designed to connect with ChatGPT Business. The public site, API, and MCP server run on separate Cloudflare deploys with clear domain boundaries.

Deploy your MCP server to mcp.derhead.app, set your auth token, then add the MCP endpoint URL in your ChatGPT Business workspace settings. See the getting started guide for step-by-step instructions.

MCP tools can trigger actions and access data. Requiring a Bearer token on every request ensures only authorized clients — like your ChatGPT Business workspace — can invoke tools.

Only harmless test tools: ping, get_status, echo, and get_time. These let you verify connectivity and auth before connecting anything sensitive. Private integrations come later, after auth, logging, and allowlists are proven in production.

api.derhead.app is your app API — REST endpoints, health checks, and backend logic. mcp.derhead.app is your MCP server — the Model Context Protocol endpoint that ChatGPT Business connects to for custom tools. They run as separate Workers so each can be secured and scaled independently.
