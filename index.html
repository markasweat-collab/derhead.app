Features

Everything you need at the bay door.

From single-truck troubleshooting to fleet-wide visibility — derhead is designed around how shops actually work.

⚡

Real-time diagnostics

Live fault codes, derate status, and sensor readings pulled straight from the ECM — no laptop shuffle required.

📊

Fleet dashboards

See every unit at a glance. Sort by severity, mileage, or shop priority so the right truck gets bay time first.

🔔

Smart alerts

Get notified when a derate kicks in, a code recurs, or a unit goes offline — before the driver calls you from the shoulder.

📋

Service history

Track repairs, parts, and code clears per unit. Know what was done last time without digging through paper work orders.

🔧

Shop workflows

Assign units to techs, log notes, and close out jobs — built for the pace of a real shop floor, not a spreadsheet.

🔗

Telematics-ready

Connects with the hardware you already run. OBD, J1939, and fleet gateway integrations are on the roadmap.

How it works

Up and running in three steps.

  1. 1

    Connect your units

    Plug in via telematics gateway or shop dongle. derhead reads live ECM data and starts building a health profile for each truck.

  2. 2

    Monitor from anywhere

    Check fault codes, derate status, and key vitals from your phone or desktop — whether you're in the bay or on the road.

  3. 3

    Fix faster, track everything

    Log the repair, clear the code, and move on. Full history stays attached to the unit so the next tech starts informed.
